# SA Textile — Home Page First

## Scope for this milestone
Build the complete responsive home page first, closely following the supplied references. Stop after the home page is ready so it can be reviewed before the About, Products, and Contact pages are completed.

## Home page
- Shared header with SA Textile branding, desktop navigation, mobile menu, and “Request a Quote” contact action.
- Full-width textile factory image with a navy overlay, large export-focused headline, and product/contact actions.
- Company introduction using the supplied Karachi and export-class positioning.
- Product preview cards for Bath Towels, Hand Towels, Face Towels / Washcloths, Cabana Towel, and Cotton Fabric.
- Trust statistics and manufacturing highlights styled like the reference.
- Dedicated company-footage section with a polished video placeholder and controls, ready for the real video file later.
- Gallery-style operations imagery and a concise contact band.
- Consistent footer with phone, WhatsApp, email, and Karachi address.

## Visual direction
- Deep navy, emerald green, crisp white, and cool neutral surfaces.
- Editorial serif headlines paired with a clean sans-serif body font.
- Rounded image corners and restrained card borders, matching the references.
- Subtle grid texture, strong photography, and restrained motion.
- Responsive layouts for mobile, tablet, and desktop.

## Content architecture
- Create one central JavaScript data file containing company details, contact links, navigation, products, statistics, page copy, and media references.
- Every home-page section and shared element reads from that file; no duplicated business or contact content.
- Use JavaScript/JSX for all newly authored site code and keep the site fully static with no submissions or backend.

## Assets and validation
- Generate cohesive textile factory, product, and operations imagery rather than embedding the screenshots themselves.
- Keep the video area ready for a later user-supplied company video; use a generated poster image for now.
- Add unique home-page metadata and verify the final page at desktop and mobile sizes.

## Deferred until home approval
- Fully designed About Us page.
- Full Products catalog page.
- Contact page with click-to-call, WhatsApp, email, and Karachi location.
